IDP Reporting 控制台用户手册

面向报表与单据的设计者、以及负责验收的测试人员。手册以 2026-11-06 的 main 分支为准（ADR 0014 的 S09-A/B/C 之后），截图由 scripts/manual_screens.sh 在一个全新的演示服务上按手册的路径自动截取，测试数据来自合同模拟器与随附的造数据脚本。

关于本手册

IDP Reporting 是一个独立的报表与单据平台：它从来源产品（现在是模拟器）取得已授权的数据，让设计者在控制台里查询、冻结快照、导出、设计看板与单据模板、发布版本、正式出具带编号的文件；来源产品也可以把其中的视图嵌进自己的页面（嵌入页）。平台不自己编号、不绕过来源授权、不在浏览器里存任何数据或令牌。

本手册随服务一起提供：控制台应用栏底部与登录卡上的"帮助"图标（/console/manual/）在新窗口打开它，不需要另外的文件共享。

本手册分三部分：十分钟上手与界面导览让你先把主要路径走一遍；页面手册逐页说明每个控件；测试数据与测试案例集给出可重复的数据、步骤与预期，并附带数据文件。

本手册里的"当前数据"指一次查询的上下文：产品连接、数据集、公司范围、数据时点、筛选与排序（数据集发布了才有），以及它是"查询预览"（可能被截断的实时结果）还是"冻结快照"（服务端固定的一份结果，分页稳定、可导出、可正式出具）。看板、模板、出具都绑定在它上面。

十分钟上手

  1. 登录。打开控制台，粘贴访问令牌（演示环境在 idp-reporting-run/token），点"连接工作区"。令牌只在内存里，退出即清除。
  2. 选择数据。登录后就在报表工作台，可以直接在查询面板里选。页眉右侧的"未选择数据"芯片，或任何页面上的"选择数据…"，都会拉开数据抽屉：选产品连接与数据集（下方列出它的字段、类型与币种），在公司范围里勾选来源产品列出的公司（演示里是"演示公司"，只有这一家时已经替你选好；来源没有名单时仍填公司 ID，如 company_demo），需要时用"添加筛选"与"添加排序"按数据集发布的字段缩小范围、排好顺序（如 账龄区间 属于 1_30，按应收余额降序），点"查询预览"或"创建快照"。结果一到，抽屉自动关闭，芯片写出数据集、公司、时点、筛选与排序（如 · 1 个筛选 · 按应收余额降序）与状态。
  3. 看结果、导出。报表工作台显示表格与服务端合计；有了冻结快照就能导出 Excel / PDF，下载前会校验文件摘要。要让文件带列标签、数字格式、小计、标记、标题与脚注，在表格上方的报表布局设计器里设好并保存，导出就按这个布局打印。
  4. 组一个看板。看板工作室：添加指标卡、明细表、柱状图，点"发布"——有未保存修改时它会先保存为新版本再发布。
  5. 从样例做一张单据。模板中心的 37 个示例模板任选一个"复制到我的模板"，把示例字段对应到你的数据集字段，进入文档工作室调整后发布。
  6. 正式出具。在应用栏的“出具”页选一张已发布模板，按冻结快照的某一行出具（文档工作室的“检查与发布 → 正式出具”也通向这一页），来源产品确认后拿到编号（如 AR-000001）并下载。
  7. 随时看任务。应用栏的"任务"在任何页面上拉开任务面板：快照、导出、出具任务的状态、取消、下载、查看结果，以及按任务 ID 恢复。

界面导览

控制台有一条常驻的应用栏（左侧 56 px）：报表、看板、模板、文档、任务、能力。它在所有页面上都在，顶部的控制台页眉（品牌与页面标签、数据芯片、身份、退出工作区）也一样。登录后进入报表工作台；数据集、字段与查询都在数据芯片打开的数据面板里，任何页面上都能打开。页面本身分两类：

  • 带页眉的页面（报表工作台、能力与环境）：页眉里有页面标签、"当前数据"芯片、环境标记、身份与"退出工作区"。
  • 工作室（文档工作室、模板中心、看板工作室）：在页眉下方、应用栏右侧占满其余空间，各有自己的工具栏（面包屑、标题与状态、版本、保存、发布等）、侧栏、检查器与状态栏，按设计原型的样式。

数据与字段

以前的“工作区概览”与“数据中心”两页并进了这里（ADR 0011）：登录后直接是报表工作台；数据集的字段与币种在数据面板里看，选好就能在同一处查询，不离开当前页面。模板中心页眉上的“数据中心”按钮、旧地址 #catalog 都打开这个面板；#overview 打开工作台。产品连接数、导出格式与身份在“能力与环境”，任务数在应用栏的角标上。

目录来自来源产品，只读：这里看不到也改不了数据集定义。切换产品连接会清空当前结果（旧结果不能冒充新查询）。“刷新目录”重新读取当前授权的数据集。

报表工作台

控件

控件作用
产品连接 / 已发布数据集当前授权目录里的组合；改动即清空结果。
公司范围来源产品列出当前身份可选的公司时是一个选择器：按名字勾选，ID 是次要文字；超过八家有筛选框；一次查询最多 16 家，选满后其余不可选并说明；名单不完整时下方多一行"输入其他公司 ID…"。来源没有名单时仍是文本框：公司 ID，多个以逗号分隔。两种情形都仍由来源产品授权（演示列出的只有"演示公司" company_demo；company_other 不在名单里，输入它会被拒绝）。会话结束什么都不记住。
数据时点查询的 as-of 日期，默认按数据集时区的今天。
筛选数据集在目录里发布了可筛选的字段时才有（演示的两个数据集都有）。"添加筛选"按名字列出还能添加的字段；一行是字段、运算符与取值。运算符只给数据集发布的那些：等于、不等于、小于、不大于、大于、不小于、属于、介于、开头为、包含。取值按字段类型：有固定取值的是下拉（"属于"时逐个勾选），日期是日期框，数字按字段的写法输入（如 100.00，原样发送），文本是文本框；"介于"填起止两个值，没有固定取值的"属于"每行一个值，最多 32 个。全部条件同时满足，一个字段一行，最多 16 行；标"必填"的行不能移除。没填好（缺值、数字写法不对、起始大于结束）时"查询预览 / 创建快照"不可用，旁边一行说明原因。结果的行与合计都是筛选后的范围：合计卡写"筛选后范围合计"，芯片、结果副标题与证据行写出筛选。改动筛选或排序与改动公司一样清空当前结果。
排序数据集发布了可排序的字段时才有：最多 3 个排序键，按先后顺序生效，一个字段一次，升序或降序（只给发布的方向）；"上移"调整先后，"移除"去掉。芯片写成 按应收余额降序，第二个键写 、再按客户升序。排序不改变合计。
查询预览实时结果，可能是有界预览；不能导出。
创建快照后台任务生成冻结结果；分页稳定；可导出、可出具。
重新校验重新读取当前快照页或重新预览。
导出 Excel / PDF导出任务完成后下载；下载前校验内容类型、文件头与 SHA-256。PDF 仅在服务端启用渲染器时出现。带筛选或排序的快照，导出的文件里写明它的范围：工作簿在 Metadata 工作表末尾，PDF 在首页元信息行之下与每页页脚。当前数据集有已保存的布局时，导出文件按它打印（列、顺序、列标签、对齐、数字格式、小计、标记、标题与脚注），按钮的提示与任务行写明用的是哪个布局的第几版；布局有未保存的修改时先弹出“导出前确认”：按已保存的版本导出，或保存后导出；设计器改过但从未保存时则是不带布局导出，或保存后导出。没有布局时导出与从前一样。
报表布局设计器折叠区：列、格式与小计。顶部一条和两个工作室相同的工具栏：保存、发布、历史，左边的徽标说明草稿 / 已保存 / 已发布。有未保存修改时“发布”给出“保存并发布”或“取消”。栏目：表格上方的标题与下方的脚注；每一列的显示、上移、对齐（左 / 居中 / 右）、列标签（空着就用数据集的名字），数值列另有格式——千分位开或关、负数用负号或括号、零写数字或横线（—）；小计按一个维度列分组（或无）；标记规则最多 8 条，每条选一列、一个关系（数值列：小于、小于等于、大于、大于等于、等于、不等于；文本列：等于、不等于、为空）、必要时一个值、一个标记（好 / 注意 / 差 / 备注，各有色块），一个单元格由第一条成立的规则上色，小计行不上色。做不到的事不提供（文本列没有格式、不能按指标小计、没有第九条规则）；数值规则的值不是数时保存与发布不可用并说明原因。用了这些的布局以 1.1 版式保存，只选列、排序、对齐的仍是 1.0。保存后，屏幕上的表格就是导出文件会打印的样子：标签与对齐、按格式显示的数字（原始精确值在单元格的提示里）、每组之后的小计行、标记的底色、标题与脚注；小计按屏幕上显示的行分组，导出文件按整个快照分组。

状态徽标

徽标含义
未查询没有当前数据。
草稿有数据，尚未保存到服务器。
已保存 vN与服务器第 N 版一致。
已发布 vN当前发布是第 N 版（需读过发布状态：打开“历史”或按“发布”都会读）。
… · 有未保存修改画布与已保存的版本不同；“发布”会先保存。
看板只保存组件与字段绑定，不含数据、令牌或公司范围；每个看板至多 12 个组件，配置至多 64 KiB；"文件"页签可导出 / 导入 JSON。

模板中心

收藏、最近使用、归档、集合都保存在服务器上，只属于当前身份；示例只读，复制后才是你的模板；没有当前数据时，编辑与复制会说明原因并提供"选择数据…"。

文档工作室

画布显示版面，不显示数据；正式输出一律由服务端渲染（PDF），浏览器预览只是画布。模板有两代：1.x 单页文本模板（固定文字、行字段、合计），2.x 分带模板（页眉 / 报表头 / 明细 / 报表尾 / 页脚，明细表流式分页、承前过次、分组合计，2.1 起含条码、二维码、图片）。

正式出具

编号由来源产品分配、文件由来源产品确认，平台不自己编号。排队中的出具任务可取消，执行中的不能；失败时任务列表写明原因（AUTH_SCOPE_DENIED 来源拒绝、ISSUE_UNRECONCILED 未能作废预留，需联系管理员）。

任务面板

任务列表只含本浏览器会话创建或恢复的任务——刷新页面后它是空的，但任务都在服务器上，用任务 ID 即可找回。这也是为什么造数据脚本会把它建的任务 ID 打印出来。

能力与环境

产品连接由平台运营方配置（ADR 0016）：先在服务端配置文件里为租户加连接，再把产品加入身份绑定；控制台只显示，不能更改。数据面板的产品下拉框会标出暂时不可用或被拒绝的产品。没有任何产品的身份登录后会看到提示，告诉您联系运营方开通。

环境模式

同一个二进制、不同参数，就是不同的测试模式（idp-reporting-run/scenario-7811.sh <mode>）：

模式参数用来测什么
normal-memory + Typst 三参数 + 四个私有目录全部功能，含 PDF
paused加 -pause-workers任务只入队不执行：取消排队任务、按 ID 恢复、状态刷新
quota加 -quota-jobs 1 -quota-results 2 -quota-admissions 3 -quota-queries 1四种限额拒绝及提示文字
nopdf去掉 Typst 参数能力无 pdf：PDF 按钮消失、预览被明确拒绝
sweep加 -sweep-interval 1m保留期清理

-memory 意味着重启即清空快照、任务与产物；模板、看板、布局在私有目录里，重启仍在。

一键造数据

node scripts/seed_demo_data.mjs --token-file ../idp-reporting-run/token --base http://127.0.0.1:7811 --out /tmp/seed.json

常见问题与边界

现象原因与做法
登录后任务面板里有别处创建的任务列表来自服务器（GET /jobs）：当前身份的任务，不分会话，每次 50 项，更早的用"加载更多"（最多 500 项）或按 ID 恢复；另一身份的任务永远不在列表里。
登录后芯片是"未选择数据"会话数据不入库。先查一次，或恢复一个快照任务后"查看结果"。
看板 / 设计器说"请先选择数据"它们绑定当前数据。任何页面上的"选择数据…"或页眉芯片都能打开抽屉。
"发布"按钮显示"保存并发布"画布有未保存修改，确认即先保存为新版本再发布；不想保存就取消。
模板中心里"编辑"是灰的没有当前数据，或模板绑定的数据集与当前数据集不同；提示里写了原因。
导出 PDF 按钮不见了 / 样例预览被拒服务端未启用 PDF 渲染器（nopdf 模式）；能力页会显示导出格式只有 xlsx。
出具按钮不出现出具在应用栏的“出具”页：需要冻结快照和一张当前数据集的已发布模板。嵌入页的对话框只接受当前发布版本且未改动的模板。
只有一个身份演示只有 user_a；"另一个身份看不到我的东西"在服务端测试里验证。
来源拒绝 / 不可用 / 出具未对账本机 UI 无法触发，属于服务端测试夹具。

快捷键与术语

快捷键作用（文档工作室）
Ctrl/⌘ K搜索命令（命令面板）
Ctrl/⌘ S保存
Ctrl/⌘ D创建所选元素的副本
Ctrl/⌘ C / X / V复制 / 剪切 / 粘贴元素（模板内剪贴板）
方向键 / Shift + 点击 / Space + 拖动微调 0.1 mm / 多选 / 平移画布
Esc关闭对话框、抽屉、面板，焦点回到打开它的控件
术语含义
查询预览实时结果，可能是有界预览；不能导出、不能出具。
冻结快照服务端固定的一份结果；分页稳定；可导出、可出具；有保留期。
版本每次保存在服务端留下的一个版本（v1、v2 …），之后不再改变；“历史”列出它们。
发布让某个版本成为当前发布版本；撤回发布是单独操作；“历史”里的“打开”不是发布。
正式出具按已发布模板与冻结快照的行（或分组）生成带编号的正式文件，编号由来源产品分配。
示例模板随平台提供的 37 个只读样例；复制后才是你的模板。
页面预设A4 / A4 横 / A5 / 4×6 in / 100×150 / 100×100 标签。
