IDP Reporting 控制台用户手册

面向报表与单据的设计者、以及负责验收的测试人员。手册以 2026-11-04 的 main 分支为准（S07-B 之后），截图来自本机演示服务上的真实操作，测试数据来自合同模拟器与随附的造数据脚本。

版本 main · 2026-11-04演示地址 http://127.0.0.1:7811/console/数据来源 合同模拟器（合成数据）浏览器 Chrome 156，1440 × 900

关于本手册

IDP Reporting 是一个独立的报表与单据平台：它从来源产品（现在是模拟器）取得已授权的数据，让设计者在控制台里查询、冻结快照、导出、设计看板与单据模板、发布版本、正式出具带编号的文件；来源产品也可以把其中的视图嵌进自己的页面（嵌入页）。平台不自己编号、不绕过来源授权、不在浏览器里存任何数据或令牌。

本手册随服务一起提供：控制台应用栏底部与登录卡上的"帮助"图标（/console/manual/）在新窗口打开它，不需要另外的文件共享。

本手册分三部分：十分钟上手与界面导览让你先把主要路径走一遍；页面手册逐页说明每个控件；测试数据与测试案例集给出可重复的数据、步骤与预期，并附带数据文件。

本手册里的"当前数据"指一次查询的上下文：产品连接、数据集、公司范围、数据时点，以及它是"查询预览"（可能被截断的实时结果）还是"冻结快照"（服务端固定的一份结果，分页稳定、可导出、可正式出具）。看板、模板、出具都绑定在它上面。

十分钟上手

  1. 登录。打开控制台，粘贴访问令牌（演示环境在 idp-reporting-run/token），点"连接工作区"。令牌只在内存里，退出即清除。
  2. 选择数据。页眉右侧的"未选择数据"芯片，或任何页面上的"选择数据…"，都会拉开数据抽屉：选产品连接与数据集，公司范围填 company_demo，点"查询预览"或"创建快照"。结果一到，抽屉自动关闭，芯片写出数据集、公司、时点与状态。
  3. 看结果、导出。报表工作台显示表格与服务端合计；有了冻结快照就能导出 Excel / PDF，下载前会校验文件摘要。
  4. 组一个看板。看板工作室：添加指标卡、明细表、柱状图，点"发布"——有未保存修改时它会先保存为新版本再发布。
  5. 从样例做一张单据。模板中心的 37 个示例模板任选一个"复制到我的模板"，把示例字段对应到你的数据集字段，进入文档工作室调整后发布。
  6. 正式出具。用"打开已发布版本"打开一个已发布模板，在"检查与发布 → 正式出具"里按冻结快照的某一行出具，来源产品确认后拿到编号（如 AR-000001）并下载。
  7. 随时看任务。应用栏的"任务"在任何页面上拉开任务面板：快照、导出、出具任务的状态、取消、下载、查看结果，以及按任务 ID 恢复。

界面导览

控制台有一条常驻的应用栏（左侧 56 px）：概览、数据、报表、看板、模板、文档、任务、能力。它在所有页面上都在，顶部的控制台页眉（品牌与页面标签、数据芯片、身份、退出工作区）也一样。页面本身分两类：

  • 带页眉的页面（概览、数据中心、报表工作台、能力与环境）：页眉里有页面标签、"当前数据"芯片、环境标记、身份与"退出工作区"。
  • 工作室（文档工作室、模板中心、看板工作室）：在页眉下方、应用栏右侧占满其余空间，各有自己的工具栏（面包屑、标题与状态、版本、保存、发布等）、侧栏、检查器与状态栏，按设计原型的样式。

工作区概览

登录后的首页。四个计数卡：当前产品连接数、所选产品的数据集数、我的任务数（控制台已读取的当前身份任务数）、可用导出格式（来自服务端能力）。"可用数据集"列出当前产品连接的数据集，"打开"把它带到工作台；"数据中心"按钮进入数据中心。右侧是三步工作流程的提示。

数据中心

目录来自来源产品，只读：这里看不到也改不了数据集定义。切换产品连接会清空当前结果（旧结果不能冒充新查询）。"刷新目录"重新读取当前授权的数据集。

报表工作台

控件

控件作用
产品连接 / 已发布数据集当前授权目录里的组合；改动即清空结果。
公司范围公司 ID，多个以逗号分隔；仍由来源产品授权（演示里只有 company_demo 会通过）。
数据时点查询的 as-of 日期，默认按数据集时区的今天。
查询预览实时结果，可能是有界预览；不能导出。
创建快照后台任务生成冻结结果；分页稳定；可导出、可出具。
重新校验重新读取当前快照页或重新预览。
导出 Excel / PDF导出任务完成后下载；下载前校验内容类型、文件头与 SHA-256。PDF 仅在服务端启用渲染器时出现。
报表布局设计器折叠区：选择列、顺序、对齐。顶部一条和两个工作室相同的工具栏：版本、保存版本、发布，左边的徽标说明草稿 / 已保存 / 已发布。有未保存修改时“发布”给出“保存并发布”。只影响屏幕显示，Excel 仍导出完整列。

看板工作室

状态徽标

徽标含义
未查询没有当前数据。
草稿有数据，尚未保存到服务器。
已保存 vN与服务器第 N 版一致。
已发布 vN发布指针指向第 N 版（需读过发布状态）。
… · 有未保存修改画布与保存版本不同；"发布"会先保存。
看板只保存组件与字段绑定，不含数据、令牌或公司范围；每个看板至多 12 个组件，配置至多 64 KiB；"文件"页签可导出 / 导入 JSON。

模板中心

收藏、最近使用、归档、集合都保存在服务器上，只属于当前身份；示例只读，复制后才是你的模板；没有当前数据时，编辑与复制会说明原因并提供"选择数据…"。

文档工作室

画布显示版面，不显示数据；正式输出一律由服务端渲染（PDF），浏览器预览只是画布。模板有两代：1.x 单页文本模板（固定文字、行字段、合计），2.x 分带模板（页眉 / 报表头 / 明细 / 报表尾 / 页脚，明细表流式分页、承前过次、分组合计，2.1 起含条码、二维码、图片）。

正式出具

编号由来源产品分配、文件由来源产品确认，平台不自己编号。排队中的出具任务可取消，执行中的不能；失败时任务列表写明原因（AUTH_SCOPE_DENIED 来源拒绝、ISSUE_UNRECONCILED 未能作废预留，需联系管理员）。

任务面板

任务列表只含本浏览器会话创建或恢复的任务——刷新页面后它是空的，但任务都在服务器上，用任务 ID 即可找回。这也是为什么造数据脚本会把它建的任务 ID 打印出来。

环境模式

同一个二进制、不同参数，就是不同的测试模式（idp-reporting-run/scenario-7811.sh <mode>）：

模式参数用来测什么
normal-memory + Typst 三参数 + 四个私有目录全部功能，含 PDF
paused加 -pause-workers任务只入队不执行：取消排队任务、按 ID 恢复、状态刷新
quota加 -quota-jobs 1 -quota-results 2 -quota-admissions 3 -quota-queries 1四种限额拒绝及提示文字
nopdf去掉 Typst 参数能力无 pdf：PDF 按钮消失、预览被明确拒绝
sweep加 -sweep-interval 1m保留期清理

-memory 意味着重启即清空快照、任务与产物；模板、看板、布局在私有目录里，重启仍在。

一键造数据

node scripts/seed_demo_data.mjs --token-file ../idp-reporting-run/token --base http://127.0.0.1:7811 --out /tmp/seed.json

脚本只走公开 API，对正在跑的演示做：两个数据集各一次预览、一份冻结快照、Excel 与 PDF 导出；8 个 1.x 模板（四个业务域、集合 客户A / 上海仓、收藏、归档、已发布、第 2 版）；4 个按字段映射复制的样例副本（对账单、波次拣货单、海运订舱、商业发票）；2 个看板（草稿、已发布三组件）；1 个已发布的报表列布局。可重复跑（到上限会跳过并说明），--only jobs,templates,samples,dashboards,layout 选择部分。

随手册附带的数据文件

以下文件由 2026-11-04 的演示导出，可直接用于手测（导入按钮）或作为接口调用的样本：

  • catalog.json — 两个产品连接的目录（数据集、列、维度、指标、时区、币种政策）。
  • query-receivables.aging.json、query-shipments.daily.json — 控制台发给 POST /queries 与 POST /snapshot-jobs 的查询规格。
  • result-receivables.aging.json、result-shipments.daily.json — 查询结果（列、行、合计、完整性、证据）；rows-receivables.aging.csv、rows-shipments.daily.csv 是同一组行的 CSV。
  • template-1x-example.json — 一个 1.0 单页模板（可在文档工作室"导入模板 JSON"打开）。
  • template-2x-example.json — 从示例"客户往来对账单"复制出的 2.1 分带模板（含明细表、group_sum、页码）。
  • dashboard-example.json — 三组件看板配置（看板工作室"文件 → 打开看板配置"）。
  • report-layout-example.json — 报表列布局（工作台"打开布局"）。
  • samples-list.json — 37 个示例模板的清单（业务域、流程、预设、元素与字段数）。
  • my-templates-listing.json — 造数据后"我的模板"列表（含目录元数据：域、流程、收藏、归档、集合、修订号、最近打开）。
  • session-and-capabilities.json — 当前身份与服务端能力（格式、限额）。

常见问题与边界

现象原因与做法
登录后任务面板里有别处创建的任务列表来自服务器（GET /jobs）：当前身份的任务，不分会话，每次 50 项，更早的用"加载更多"（最多 500 项）或按 ID 恢复；另一身份的任务永远不在列表里。
登录后芯片是"未选择数据"会话数据不入库。先查一次，或恢复一个快照任务后"查看结果"。
看板 / 设计器说"请先选择数据"它们绑定当前数据。任何页面上的"选择数据…"或页眉芯片都能打开抽屉。
"发布"按钮显示"保存并发布"画布有未保存修改，确认即先保存为新版本再发布；不想保存就取消。
模板中心里"编辑"是灰的没有当前数据，或模板绑定的数据集与当前数据集不同；提示里写了原因。
导出 PDF 按钮不见了 / 样例预览被拒服务端未启用 PDF 渲染器（nopdf 模式）；能力页会显示导出格式只有 xlsx。
出具按钮不出现只有"打开已发布版本"后未改动的模板才能出具；需要冻结快照。
只有一个身份演示只有 user_a；"另一个身份看不到我的东西"在服务端测试里验证。
来源拒绝 / 不可用 / 出具未对账本机 UI 无法触发，属于服务端测试夹具。

快捷键与术语

快捷键作用（文档工作室）
Ctrl/⌘ K搜索命令（命令面板）
Ctrl/⌘ S保存版本
Ctrl/⌘ D创建所选元素的副本
Ctrl/⌘ C / X / V复制 / 剪切 / 粘贴元素（模板内剪贴板）
方向键 / Shift + 点击 / Space + 拖动微调 0.1 mm / 多选 / 平移画布
Esc关闭对话框、抽屉、面板，焦点回到打开它的控件
术语含义
查询预览实时结果，可能是有界预览；不能导出、不能出具。
冻结快照服务端固定的一份结果；分页稳定；可导出、可出具；有保留期。
保存版本模板 / 看板 / 布局在服务端的不可变版本（v1、v2 …）。
发布把发布指针移到某个保存版本；撤回是单独操作；恢复到编辑器不是发布。
正式出具按已发布模板与冻结快照的行（或分组）生成带编号的正式文件，编号由来源产品分配。
示例模板随平台提供的 37 个只读样例；复制后才是你的模板。
页面预设A4 / A4 横 / A5 / 4×6 in / 100×150 / 100×100 标签。
