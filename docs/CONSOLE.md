# 独立控制台与基础报表查看器

界面由现有 Go 服务直接提供，地址 /console/。无需 Node、npm 或前端构建即可
运行已编译的服务。Node/jsdom 仅用于开发测试。当前数据和身份仍是合同模拟器。

## 本机启动

    go build -o bin/reporting-demo ./cmd/reporting-demo
    export REPORTING_DEMO_TOKEN="$(openssl rand -hex 32)"
    ./bin/reporting-demo -profile contract-simulator -memory

在本机浏览器打开 http://127.0.0.1:7810/console/，输入本次配置的令牌。公司选择
可用 company_demo（这是合成示例；仍由来源授权检查）。令牌不写入 URL、浏览器
Storage、日志或任务；退出/401 清理当前页面数据。仅使用回环环境或可信 HTTPS
部署，浏览器需要安全上下文的 Web Crypto 完成文件摘要校验。

-memory 明确是临时存储，重启丢失状态。既有受保护的双 PostgreSQL 测试库模式
同样提供该控制台，启动参数及库名保护见历史 S01-B 文档；本轮未重复 PG 验收，
不声称生产部署或新界面已完成 PG/浏览器联测。

## 可操作内容

- 概览与目录：当前身份、产品连接、已授权数据集、字段类型/精度/币种和批准组合。
- 工作台：公司选择、数据时点、预览、创建异步快照、同快照分页、重新校验、
  Excel 任务与摘要校验后的文件下载；服务端提供 PDF 时另有“导出 PDF”。下载按格式
  校验内容类型、文件头与 SHA-256。金额/大整数保持原字符串。
- 文档模板设计器：A4 单页文本模板（固定文字、行字段、原范围合计），毫米控件编辑位置与字号，私有版本、发布与撤回，
  预印纸偏移与变量层，私有 PNG 底稿；按冻结快照的一行生成带 PREVIEW 标记的 PDF 预览，下载前校验内容类型、文件头与
  摘要；服务端能力未列出 pdf 时不显示两个预览按钮。没有拖拽画布。明细表面板（S03-F）：选择当前授权结果的 1–12 个字段、
  区域与字号，生成 schema 1.3 模板，第一列按字号给足承前/过次标签（按 100 页计）、其余列宽平均分配（可在 JSON 中调整，
  之和须等于表宽），预览按冻结快照的全部行多页续页；服务端因列宽放不下金额或标签拒绝时，控制台提示为模板排版问题。
  正式出具面板（S03-G，S03-H 起以来源产品为准，见 ADR_0003）：用“打开已发布模板”打开发布版本且未改动时，“正式出具”按当前
  冻结快照与行号提交 issue 任务（幂等键、轮询）。编号由来源产品分配、文件由来源产品确认，平台不自行编号：提交后控制台提示
  任务在等待来源产品确认编号，任务列表在排队中与执行中显示“正式出具（编号待来源产品确认）”，失败或取消显示“正式出具（未出具）”；
  任务成功后才有编号，列表改为“正式出具 No. AR-000012”，文件按编号下载为 `issued-AR-000012.pdf` 并在提示中写明编号。
  编号是 1–32 个 `A-Za-z0-9._-` 字符的字符串（以字母或数字开头），只出现在已成功的任务与记录里：整数编号、未成功任务上的编号
  或不合规的编号都按无法验证的响应处理。排队中的出具任务可取消，执行中的不显示取消（它会完成，或失败并通知来源产品作废预留；
  取消请求若恰好晚于开始执行，服务端原样返回，控制台如实提示）。任务失败时说明原因：AUTH_SCOPE_DENIED 表示来源产品拒绝出具
  （无权限、单据未获批准，或来源数据已变化）；ISSUE_UNRECONCILED 表示失败后平台未能通知来源产品作废其预留，需联系管理员并提供
  任务 ID；其余错误码照常显示。服务端能力未声明 issuance 时不显示该按钮；只能出具已发布版本，服务端拒绝（TEMPLATE_NOT_PUBLISHED）
  时提示刷新发布状态。提交被 422 UNSUPPORTED_COMBINATION 拒绝时（来源产品不支持正式出具或服务端未启用出具；同一错误码在受理时
  也表示所选行含有无法打印的值，或模板底稿在当前服务端不可用），控制台给出出具专用提示，而不是“数据集不支持此查询组合”；任务本身
  以该错误码失败时（渲染器的排版拒绝也用它）只显示错误码。“刷新出具记录”列出当前身份的出具记录（编号、状态、UTC 出具时间、模板
  版本、快照与行、PDF 摘要与页数、来源产品的确认引用与确认时间），逐条按服务端给出的形状校验后才显示：编号为字符串、已出具的记录
  带有预留引用与确认引用（1–128 字符）和不早于出具时间的确认时间、印章按编号、出具时间与记录 ID 重新计算、未出具的记录不带编号与
  确认信息，记录数超过 100 条即整体拒绝；失败的记录显示错误码并对上述两种失败给出简短说明。已出具的可再次下载，下载字节须与记录的
  SHA-256 一致；服务端按记录 ID 命名文件（issued-<记录 ID>.pdf），控制台按编号另存（issued-AR-000012.pdf）。
- 任务工作区：当前会话已知任务的刷新、显式取消（执行中的出具任务除外）、结果查看与文件下载。失败的任务（任何类型）在状态栏
  显示错误码，如 `失败 · ISSUE_UNRECONCILED`，刷新或恢复后仍可见；错误码只在失败的任务上出现且须为大写字母、数字与下划线，
  否则按无法验证的响应处理。可输入当前身份有权访问的任务 ID 恢复查看；不冒充完整数据库任务历史。
- 能力与环境：服务端能力、合成数据说明与尚未完成的能力。

当前只有已发布查询组合，自定义筛选、排序、SQL、公式不开放。画布编辑器、
嵌入入口、出具 PDF 的保留策略及生产运行仍在后续范围；PDF 目前只有
内置的通用表格版式与文档模板。

## 状态与权限

查询预览不是可恢复的冻结快照，不能直接导出为原件。先创建快照，再生成导出。
每次新操作使用独立幂等键；响应尚未确认的同一提交重试复用键。换查询或退出
不会取消服务器任务；取消必须点击明确操作。旧请求返回不得替换新查询结果。

所有数据/任务/下载均经现有 API 检查；布局不携带作者权限。403、授权故障或
完整性异常停止显示对应结果；401 清除会话。已下载/已看到的信息无法被远程
撤回，本界面不承诺消除浏览器外的用户副本。
