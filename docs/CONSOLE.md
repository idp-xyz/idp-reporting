# 独立控制台与基础报表查看器

界面由现有 Go 服务直接提供，地址 /console/。无需 Node、npm 或前端构建即可
运行已编译的服务。Node/jsdom 仅用于开发测试。当前数据和身份仍是合同模拟器。

## 本机启动

    go build -o bin/reporting-demo ./cmd/reporting-demo
    export REPORTING_DEMO_TOKEN="$(openssl rand -hex 32)"
    ./bin/reporting-demo -profile contract-simulator -memory

在本机浏览器打开 http://127.0.0.1:7810/console/，输入本次配置的令牌。公司选择
可用 company_demo（这是合成示例；仍由来源授权检查）。令牌不写入 URL、浏览器
Storage、日志或任务；退出/401 清理当前页面数据。仅使用回环环境或可信 HTTPS
部署，浏览器需要安全上下文的 Web Crypto 完成文件摘要校验。

-memory 明确是临时存储，重启丢失状态。既有受保护的双 PostgreSQL 测试库模式
同样提供该控制台，启动参数及库名保护见历史 S01-B 文档；本轮未重复 PG 验收，
不声称生产部署或新界面已完成 PG/浏览器联测。

## 可操作内容

- 概览与目录：当前身份、产品连接、已授权数据集、字段类型/精度/币种和批准组合。
- 工作台：公司选择、数据时点、预览、创建异步快照、同快照分页、重新校验、
  Excel 任务与摘要校验后的文件下载；服务端提供 PDF 时另有“导出 PDF”。下载按格式
  校验内容类型、文件头与 SHA-256。金额/大整数保持原字符串。
- 文档模板设计器：A4 单页文本模板（固定文字、行字段、原范围合计），毫米控件编辑位置与字号，私有版本、发布与撤回，
  预印纸偏移与变量层，私有 PNG 底稿；按冻结快照的一行生成带 PREVIEW 标记的 PDF 预览，下载前校验内容类型、文件头与
  摘要；服务端能力未列出 pdf 时不显示两个预览按钮。画布见下一条。明细表面板（S03-F）：选择当前授权结果的 1–12 个字段、
  区域与字号，生成 schema 1.3 模板，第一列按字号给足承前/过次标签（按 100 页计）、其余列宽平均分配（可在 JSON 中调整，
  之和须等于表宽），预览按冻结快照的全部行多页续页；服务端因列宽放不下金额或标签拒绝时，控制台提示为模板排版问题。
  正式出具面板（S03-G，S03-H 起以来源产品为准，见 ADR_0003）：用“打开已发布模板”打开发布版本且未改动时，“正式出具”按当前
  冻结快照与行号提交 issue 任务（幂等键、轮询）。编号由来源产品分配、文件由来源产品确认，平台不自行编号：提交后控制台提示
  任务在等待来源产品确认编号，任务列表在排队中与执行中显示“正式出具（编号待来源产品确认）”，失败或取消显示“正式出具（未出具）”；
  任务成功后才有编号，列表改为“正式出具 No. AR-000012”，文件按编号下载为 `issued-AR-000012.pdf` 并在提示中写明编号。
  编号是 1–32 个 `A-Za-z0-9._-` 字符的字符串（以字母或数字开头），只出现在已成功的任务与记录里：整数编号、未成功任务上的编号
  或不合规的编号都按无法验证的响应处理。排队中的出具任务可取消，执行中的不显示取消（它会完成，或失败并通知来源产品作废预留；
  取消请求若恰好晚于开始执行，服务端原样返回，控制台如实提示）。任务失败时说明原因：AUTH_SCOPE_DENIED 表示来源产品拒绝出具
  （无权限、单据未获批准，或来源数据已变化）；ISSUE_UNRECONCILED 表示失败后平台未能通知来源产品作废其预留，需联系管理员并提供
  任务 ID；其余错误码照常显示。服务端能力未声明 issuance 时不显示该按钮（issuance 仅在服务端没有 issuer 时为 false；有 issuer 但未启用 pdf 格式时它仍为 true、`POST /issues` 回 422，控制台因 formats 不含 pdf 同样不显示该按钮）；只能出具已发布版本，服务端拒绝（TEMPLATE_NOT_PUBLISHED）
  时提示刷新发布状态。提交被 422 UNSUPPORTED_COMBINATION 拒绝时（来源产品不支持正式出具或服务端未启用出具；同一错误码在受理时
  也表示所选行含有无法打印的值，或模板底稿在当前服务端不可用），控制台给出出具专用提示，而不是“数据集不支持此查询组合”；任务本身
  以该错误码失败时（渲染器的排版拒绝也用它）只显示错误码。“刷新出具记录”列出当前身份的出具记录（编号、状态、UTC 出具时间、模板
  版本、快照与行、PDF 摘要与页数、来源产品的确认引用与确认时间），逐条按服务端给出的形状校验后才显示：编号为字符串、已出具的记录
  带有预留引用与确认引用（1–128 字符）和不早于出具时间的确认时间、印章按编号、出具时间与记录 ID 重新计算、未出具的记录不带编号与
  确认信息，记录数超过 100 条即整体拒绝；失败的记录显示错误码并对上述两种失败给出简短说明。已出具的可再次下载，下载字节须与记录的
  SHA-256 一致；服务端按记录 ID 命名文件（issued-<记录 ID>.pdf），控制台按编号另存（issued-AR-000012.pdf）。
- 文档画布（S03-I，docs/S03I_SCOPE.md）：文档模板设计器顶部的 A4 画布（210 × 297 毫米，固定比例 100% 时 1 毫米 = 3 像素，缩放 50–200%）。
  上边与左边是毫米标尺；虚线为安全区（x 10–200、y 25–270），浅橙色横条为横幅与出具印章保留区（10–18 毫米，不可选）；每个文本框
  显示编号、来源（固定文字、行字段、合计）与文字或字段名，按其字号绘制，明细表显示区域、表头字段名与列边界；整体偏移不为 0 时以
  虚线描出偏移后的打印位置，变量层模式下固定文字灰显（不打印）。画布只显示版面，不显示底稿与数据，PDF 预览为准。
  操作：点击选择，Shift 点击增减，点击空白或 Esc 清除，Ctrl/Cmd+A 全选（文本框与明细表）；拖动移动所选项目；单选时拖动
  四角与四边手柄调整大小（明细表同理，列宽按比例缩放，取 0.1 毫米，余数落在最后一列）；拖动明细表列线调整列宽（右侧一列让出或
  取得宽度，表宽不变，每列不小于 8 毫米，第一列不小于承前/过次标签所需宽度）。位置与大小默认吸附 1 毫米，按住 Alt 为 0.1 毫米，
  并在 1 毫米内吸附其他项目的边与中心，同时显示参考线与当前位置。方向键微调 0.1 毫米，Shift+方向键 1 毫米；Delete 或 Backspace
  删除所选（明细表一并删除后模板退回 1.2 或 1.1；最后一个文本框不可删）；Ctrl/Cmd+D 复制文本框（取最小的空闲编号，放在其正下方
  最近的空位，满 24 个时拒绝）；对齐（左、水平居中、右、顶、垂直居中、底，两项或更多）与等距分布（水平、垂直，三项或更多）按
  所选项目的外框计算，取 0.1 毫米。模板规则不接受的修改（超出安全区、重叠、过小、最后一个文本框、超过 24 个、偏移后出界等）不会生效：
  项目回到原位，画布下方状态行（role=status）写明原因，不产生撤销步骤。1.0 模板被改到非整毫米时升为 1.1，与输入框一致。
  画布从不绕过设计器：每次修改都生成完整模板配置，交给与输入框相同的校验与规范化（apply）后才生效；输入框与画布双向同步。
  撤销与重做：任何被接受的模板修改（画布、输入框、添加/移除、明细表、套打设置、底稿引用）各为一步，一次拖动为一步，至少 100 步
  （上限 200 步）；Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y 重做（文本框内仍用输入框自己的撤销）。打开模板（JSON、服务器版本、
  已发布版本）、重置模板与新的查询会清空历史；同一冻结快照翻页不清空。撤销不会恢复“刚打开已发布版本且未改动”的状态：任何修改之后，
  正式出具仍须重新“打开已发布模板”。命令面板：Ctrl/Cmd+K（或“命令面板”按钮）打开模态对话框，列出设计器的操作（添加固定文字/行字段/
  合计、添加或移除明细表、对齐与分布、复制、删除、撤销、重做、PDF 预览、检查样本、保存版本、发布、打开已发布模板、正式出具），
  输入过滤，上下键选择，Enter 执行对应按钮的点击；只列出按钮存在、可见且可用的操作；焦点困在对话框内，Esc 关闭并还原焦点。
  键盘与读屏：Tab 按阅读顺序（自上而下、自左向右）遍历项目，Enter 或空格选择；每个项目有可读名称（编号、来源、文字或字段、位置与大小）；
  选择变化经礼貌型 live 区域播报；选中明细表后可 Tab 到列边界（滑块），左右方向键调整。页面在 390、768、1280 像素宽度下无横向溢出，
  画布在自己的面板内滚动；颜色取自一组变量，浅色与深色方案下文字对比度不低于 4.5:1、轮廓不低于 3:1（控制台本身目前只有浅色主题，画布的
  桌面与标尺随系统深色方案变化，纸面始终为白色）。
  检查样本：用当前模板检查当前冻结快照的首行、末行与各行字段最长/最短值所在的行（POST /document-checks，不渲染 PDF，不含 Typst），
  逐行显示结果、错误码（如 UNSUPPORTED_COMBINATION：值放不下所在框或列，或含字体不支持的字符）与选取原因，可一键把某行载入预览行号；
  修改模板后结果作废。检查只核对版面（字体、字符、尺寸），Typst 渲染才能发现的问题仍以 PDF 预览为准；需要冻结快照，且服务端挂载了该路由
  （与 PDF 预览同时提供），否则提示未启用。画布不含：条码、图片、锁定、旋转、底稿显示与工作室模板库；2.0 分带模板见下面的 S03-L 条目。
- 模板 schema 2.0（S03-J，ADR 0004：分带、分组、换行文本、线与矩形）：设计器经“模板元数据JSON”打开、预览、检查样本、保存与发布 2.0 模板，
  校验与规范化与服务端相同的封闭形式（doctemplates/testdata/schema2_cases.json 的共享用例同时由 Go 测试与 DOM 测试运行：未知键、类型、来源、
  带与字段一律拒绝，分组字段须是维度、分组合计须是指标）。画布与面板编辑 2.0 模板见下面的 S03-L 条目（S03-J 只有 JSON；那时画布处显示“画布只显示 1.x 模板”，现已不再）。预览以所给行号所在的分组生成文档。已发布的 2.0 模板（“打开已发布模板”后未改动）按该行号所在的分组正式出具（S03-K）：
  控制台提交的请求与 1.x 相同（模板、版本、快照与行号 `row_index`），由服务端在冻结快照中确定该行的分组并冻结；出具确认、任务与出具记录显示
  分组字段与键值（如 `customer.id = customer_c（1 行）`；模板无分组字段时显示“整个快照”；过长的键值只在显示时截断）而不显示行号，
  控制台只接受形状已知的 `group`（`fields`、`key`、`row_count`、`rows_sha256`），2.0 模板的任务视图若带行号或 1.x 模板的任务视图若带分组，
  即按无法验证的响应处理。来源产品须声明支持分组出具（合同版本 2），否则服务端在受理时以 422 拒绝，控制台说明原因。
  1.x 模板不变，字节不变，仍按行出具。
- 2.0 分带模板的画布、面板与转换（S03-L，ADR 0004，docs/S03L_SCOPE.md）：仅控制台，服务端不变；每次修改仍生成完整配置，交给与 1.x 相同的校验与规范化
  （apply，含与服务端共用用例的 2.0 校验）后才生效，拒绝时留在原样并给出校验器的原因；位置取 0.1 毫米整数单位。
  绘制：2.0 模板按页面自上而下画出：横幅与印章保留区，然后从安全区顶部（y 25 毫米）起依次是页眉带、单据头带、明细带、单据尾带，页脚带在安全区底部（y 270 毫米）；
  每带是着色、带虚线轮廓的区域，其名称与高度写在页面右侧的边栏里（不压在元素上），明细带写“约 N 毫米”与“随页面伸展”：它占满其余各带留下的空间，但不少于明细表的最小高度
  （表头、承前行、一行明细与过次或合计行，按字号计），单据尾带紧随其后（放不下时标出“放不下时移到新页”）。元素画在带内（位置 = 带的顶边加元素自己的 y）：
  文本显示来源（固定文字、字段〔字段名〕、分组合计〔合计〕字段名、页码文字原样显示 {page} 与 {pages}）、对齐、粗体与自动换行记号（↵）；线按线宽画在两点之间；
  矩形按填充灰度与线宽画；明细表显示表头（字面表头文字优先于字段标签）、列边界与一行示例行（金额列默认右对齐）。分组字段、带高与重叠由模板规则判断，画布只显示版面，PDF 预览为准。
  编辑：1.x 画布的全部操作对 2.0 元素同样适用（点击、Shift 点击、Esc、Ctrl/Cmd+A、拖动、手柄调整大小、吸附 1 毫米与 Alt 的 0.1 毫米、方向键微调、对齐、等距分布、
  复制到最小的空闲 e 编号并放在带内最近的空位、删除、撤销与重做、命令面板）。吸附除 1 毫米网格外，只对同一带内其他元素的边与中心以及该带自己的边与中心（1 毫米内，出现参考线）；
  网格以带内坐标计。把元素拖过带的分界线时，指针所在的带接收它（位置改为相对该带；选中的元素都在同一个带时才换带，选中明细表时不换带）；模板规则拒绝的移动回到原位并说明原因。
  固定带的下边缘可拖动调整带高（吸附整毫米、Alt 为 0.1 毫米、最低元素的底边），也可 Tab 到该边缘用上下方向键调整（0.1 毫米，Shift 1 毫米）；明细带没有可拖动的边缘。
  线用本体移动、用两个端点手柄编辑（鼠标或 Tab 后方向键；端点吸附网格、同带元素、带边与另一端点，便于画出水平线与竖线），不使用八个缩放手柄；明细表只有左右两个手柄（列宽按比例缩放，余数落在最后一列），
  纵向位置由各带高度决定；明细表列边界的拖动与 1.x 相同（每列不小于 8 毫米；2.0 没有第一列的标签宽度下限，放不下由预览指出）。明细表不能删除也不能复制。
  面板（选中 2.0 模板时取代 1.x 的元素、明细表、底稿与套打面板）：分组字段（三个下拉，只列维度，可不选）；带（添加或移除可选带，高度输入；移除带连同其元素，一步撤销）；
  添加元素（选带；固定文字、字段文本、分组合计、页码文字、线、矩形；新元素取最小空闲编号、放在带内第一个空位并被选中；页码文字须含 {page} 或 {pages}，分组合计取指标字段）；
  所选元素的属性（该类型的每个键都是经校验的输入：来源、文字或字段、x、y、宽、高、字号、对齐、粗体、自动换行，线的端点与线宽，矩形的填充与线宽，以及所在带）；
  明细表（x、表宽、字号，表宽改变时各列按比例缩放；每列的字段、宽度（由右邻列补足，最后一列由左邻列补足）、字面表头文字、对齐，上移、下移、移除；添加列取走最宽一列的一半）。
  输入与画布双向同步，每次被接受的修改是一步撤销，被拒绝的输入退回并显示校验器的原因；面板就地更新，Tab 与点击不丢焦点。
  转换：1.x 模板旁的“转换为 2.0”（命令面板同）在本页把当前 1.x 模板变成 2.0 配置，作为未保存的修改打开（一步撤销，保存才成为模板的下一个版本，服务器不转换任何内容；
  先预览再保存）。映射：表格上方的文本框（无表格时是全部文本框）成为单据头，位置相对安全区顶部（25 毫米），带高到表格的顶边，所以其页面位置与 1.x 预览相同；
  表格成为明细带的表（列与宽度不变）；表格区域下方的文本框成为单据尾，位置相对表格区域的下边，2.0 把单据尾放在明细表最后一行之后，所以这些框不再停在原来的页面位置，转换说明里会写明；
  行字段成为分组字段文本，合计成为分组合计，固定文字不变；元素编号 e1… 自上而下；不设分组（整个快照一份文档），行字段文本因此要求各行取值相同，须在“分组字段”中选择维度字段，

## 状态与权限

查询预览不是可恢复的冻结快照，不能直接导出为原件。先创建快照，再生成导出。
每次新操作使用独立幂等键；响应尚未确认的同一提交重试复用键。换查询或退出
不会取消服务器任务；取消必须点击明确操作。旧请求返回不得替换新查询结果。

所有数据/任务/下载均经现有 API 检查；布局不携带作者权限。403、授权故障或
完整性异常停止显示对应结果；401 清除会话。已下载/已看到的信息无法被远程
撤回，本界面不承诺消除浏览器外的用户副本。
