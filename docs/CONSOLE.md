# 独立控制台与基础报表查看器

界面由现有 Go 服务直接提供，地址 /console/。无需 Node、npm 或前端构建即可
运行已编译的服务。Node/jsdom 仅用于开发测试。当前数据和身份仍是合同模拟器。

## 本机启动

    go build -o bin/reporting-demo ./cmd/reporting-demo
    export REPORTING_DEMO_TOKEN="$(openssl rand -hex 32)"
    ./bin/reporting-demo -profile contract-simulator -memory

在本机浏览器打开 http://127.0.0.1:7810/console/，输入本次配置的令牌。公司选择
可用 company_demo（这是合成示例；仍由来源授权检查）。令牌不写入 URL、浏览器
Storage、日志或任务；退出/401 清理当前页面数据。仅使用回环环境或可信 HTTPS
部署，浏览器需要安全上下文的 Web Crypto 完成文件摘要校验。

-memory 明确是临时存储，重启丢失状态。既有受保护的双 PostgreSQL 测试库模式
同样提供该控制台，启动参数及库名保护见历史 S01-B 文档；本轮未重复 PG 验收，
不声称生产部署或新界面已完成 PG/浏览器联测。

## 可操作内容

- 概览与目录：当前身份、产品连接、已授权数据集、字段类型/精度/币种和批准组合。
- 工作台：公司选择、数据时点、预览、创建异步快照、同快照分页、重新校验、
  Excel 任务与摘要校验后的文件下载；服务端提供 PDF 时另有“导出 PDF”。下载按格式
  校验内容类型、文件头与 SHA-256。金额/大整数保持原字符串。
- 文档模板设计器：A4 单页文本模板（固定文字、行字段、原范围合计），毫米控件编辑位置与字号，私有版本、发布与撤回，
  预印纸偏移与变量层，私有 PNG 底稿；按冻结快照的一行生成带 PREVIEW 标记的 PDF 预览，下载前校验内容类型、文件头与
  摘要；服务端能力未列出 pdf 时不显示两个预览按钮。没有拖拽画布。明细表面板（S03-F）：选择当前授权结果的 1–12 个字段、
  区域与字号，生成 schema 1.3 模板，第一列按字号给足承前/过次标签（按 100 页计）、其余列宽平均分配（可在 JSON 中调整，
  之和须等于表宽），预览按冻结快照的全部行多页续页；服务端因列宽放不下金额或标签拒绝时，控制台提示为模板排版问题。
  正式出具面板（S03-G）：用“打开已发布模板”打开发布版本且未改动时，“正式出具”按当前冻结快照与行号提交 issue 任务
  （幂等键、轮询、按编号下载 `issued-000012.pdf`），任务列表显示“正式出具 No. 000012”；服务端能力未声明 issuance 时不显示
  该按钮；只能出具已发布版本，服务端拒绝（TEMPLATE_NOT_PUBLISHED）时提示刷新发布状态。“刷新出具记录”列出当前身份的出具记录
  （编号、状态、UTC 时间、模板版本、快照与行、PDF 摘要与页数），逐条校验记录与印章一致后才显示，已出具的可再次下载。
- 任务工作区：当前会话已知任务的刷新、显式取消、结果查看与文件下载。可输入
  当前身份有权访问的任务 ID 恢复查看；不冒充完整数据库任务历史。
- 能力与环境：服务端能力、合成数据说明与尚未完成的能力。

当前只有已发布查询组合，自定义筛选、排序、SQL、公式不开放。画布编辑器、
嵌入入口、出具 PDF 的保留策略及生产运行仍在后续范围；PDF 目前只有
内置的通用表格版式与文档模板。

## 状态与权限

查询预览不是可恢复的冻结快照，不能直接导出为原件。先创建快照，再生成导出。
每次新操作使用独立幂等键；响应尚未确认的同一提交重试复用键。换查询或退出
不会取消服务器任务；取消必须点击明确操作。旧请求返回不得替换新查询结果。

所有数据/任务/下载均经现有 API 检查；布局不携带作者权限。403、授权故障或
完整性异常停止显示对应结果；401 清除会话。已下载/已看到的信息无法被远程
撤回，本界面不承诺消除浏览器外的用户副本。
