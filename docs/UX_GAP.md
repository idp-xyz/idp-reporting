# 界面差距清单：原型 IDP_Reporting_Designer_UIUX_V3.0 与当前控制台

2026-11-02。用同一台无头 Chrome（Windows，经 CDP）在 1440 × 900 下分别截取原型与当前控制台（主分支 1aa33fe，演示服务）的页面，逐项比较。截图在 `evidence/ux-gap/`，脚本是 `scripts/browser_ux_gap.mjs`（原型由脚本从本机回环地址临时提供）。原型是用户的交互原型，是界面与交互的规格；本清单只说"有什么、缺什么"，不说优先级，优先级在 ADR 0008 与各切片范围里。

## 结论

现在的控制台沿用的是 S03-A 的通用后台布局（左侧导航、卡片、长表单），原型里的编辑行为（选择、拖动、吸附、对齐、撤销、命令面板、边界样例、套打、分带、条码）大部分已经实现，但**外观、版式与导航结构没有一处照原型做**。差距不在功能点上，而在整个壳子：

| 层面 | 原型 | 当前控制台 |
|---|---|---|
| 整体 | 全屏"文档工作室"，一个模板占满整屏 | 后台布局，设计器是一页长滚动页 |
| 顶栏 | 品牌、"模板中心 ›"面包屑、模板名可改、草稿/发布状态徽标、帮助、版本、保存版本、预览与导出、发布 | 面包屑、合同模拟器徽标、用户名、退出 |
| 功能区 | 五个页签（设计、插入、数据、页面、检查与发布）各一行工具按钮，右侧"搜索命令 ⌘K" | 一排文字按钮（撤销、重做、复制、删除、对齐六种、等距两种）、缩放滑杆、命令面板按钮、检查样本 |
| 左侧 | 工具栏（组件、数据、结构、资源、模板、帮助）切换四个面板：组件库（基础内容、数据与结构、专业单据三组卡片）、数据与字段（数据集卡、搜索、单据级与明细级字段列表）、区段与图层（按带列出元素，锁定与可见）、资源与样式 | 无；元素的添加是画布下方的一行输入与按钮；字段来自"当前授权字段"下拉 |
| 画布 | 顶部上下文条（模板名、示例条数、参数与筛选、查看数据）、水平标尺、左侧带标签（页眉、报表头、明细区、报表尾）、A4 页面居中、底部页码器与"适合宽度"缩放、拖拽提示 | 深色底、双向标尺、横幅保留区、A4 页面、缩放滑杆在画布上方；带标签在页面右侧（2.0 模板） |
| 右侧 | 页面属性面板，三个页签（属性、规则、检查），纸张与布局卡、区段设置、元素属性 | 无右栏；元素属性在画布下方的输入行里 |
| 状态栏 | 版式检查结果、当前选中、毫米定位、数据来源 | 无 |
| 模板中心 | 独立页面：快捷访问（全部、收藏、最近、归档）、业务域（仓储 WMS 24、运输/货代 7、国际贸易 4、通用业务 2）、搜索、流程/状态/排序筛选、列表与网格、37 个模板卡（状态徽标、版本数、收藏、分类、复制、归档、编辑）、导入模板、新建模板、数据中心入口 | 无模板库；模板按身份保存在服务端（每身份 16 个），用"打开服务器版本"下拉选择 |
| 版本 | 对话框"版本历史与发布指针"：版本列表、当前发布、预览此版本、恢复到编辑器、撤回发布、发布此保存版本 | 同样的语义（不可变版本、按版本发布、恢复不等于重新发布、撤回单独操作）以一组按钮和状态文字呈现 |
| 新建向导 | 有（选择业务流程、数据、版式） | 无；新模板从默认的一个文本框开始 |
| 命令面板 | ⌘K，搜索命令 | Ctrl/Cmd-K，已实现 |
| 其余页面 | 原型只有工作室与模板中心 | 工作区概览、数据目录、报表工作台、看板设计器、任务工作区、能力与环境，均为后台卡片风格 |

## 组件对照

| 原型组件 | 服务端现状 | 处理 |
|---|---|---|
| 文本、绑定字段、分隔线、矩形容器 | 有（2.0 的 text / line / rect，字段来源） | 直接对应 |
| 动态明细表（流式分页、重复表头、每页小计、承前过次） | 有（明细带、多页、表头重复、分组合计） | 直接对应；每页小计与承前过次需核对 |
| 条形码、二维码、图片/标识 | 有（2.1） | 直接对应 |
| 页码信息 | 有（页码文字 {page}/{pages}） | 直接对应 |
| 签章栏 | 无 | 以矩形加固定文字表示，面板里标注"签章与签名属于后续阶段" |
| 水印 | 无 | 不实现，面板里置灰并说明 |
| 计算指标、金额摘要 | 部分（分组合计 group_sum） | 能映射为分组合计的映射，其余置灰并说明 |
| 套打（MAWB 引导图、变量层、整体偏移） | 有（1.x 的套打偏移与底稿） | 直接对应；2.x 的套打未做 |

## 原型里不能照搬的

- 浏览器预览与打印当正式输出：正式文件只由服务端的 Typst 生成（ADR 0001/0002）。
- 本地保存、版本与发布放在 localStorage：平台的模板、版本与发布在服务端。
- CSV 样例当数据源：数据来自来源产品的冻结快照与字段目录。
- 页面生成正式文件里的条码（内嵌 bwip-js）：条码由服务端画矢量，画布只画占位。
- 37 个模板里的业务校验（危险品 UN 编号、折扣上限、报价有效期）：属于来源产品，平台不做。

## 技术约束（原型代码不能原样合并的原因）

- 控制台的 CSP 不允许内联脚本与内联样式，位置用 CSSOM 与 SVG 属性设置；原型有大量 `style=` 与 `innerHTML` 拼接。
- 控制台运行时没有第三方代码；原型内嵌 bwip-js（约 358 KB）。
- 控制台每个视图都有 DOM 测试与无障碍要求（键盘、名称、活动区域）；原型没有。
- 原型的 CSS（约 62 KB）与版式可以作为设计系统迁入；JS（约 315 KB）只能当行为规格。
