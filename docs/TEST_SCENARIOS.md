# 测试场景与数据准备

2026-11-04。本文回答两个问题：现在这套系统（控制台、设计器、嵌入页、服务端）在本机能测哪些场景，以及每个场景要的数据从哪里来。数据来源只有一个：合同模拟器（`adapters/contractsim`），它是服务端的"来源产品"替身，数据与授权规则写死在代码里，可预测、可重复。真实产品与企业身份按约定放在最后，这里不涉及。

## 1. 环境与模式

演示服务在 `127.0.0.1:7811`，令牌在 `idp-reporting-run/token`（登录卡里粘贴）。同一个二进制用不同参数起，就是不同的测试模式（`idp-reporting-run/scenario-7811.sh <mode>`；参数本身见 `go run ./cmd/reporting-demo -h`）：

| 模式 | 参数 | 用来测什么 |
|---|---|---|
| `normal` | `-memory` + Typst 三个参数 + 四个私有目录 | 日常全部功能，含 PDF 预览/导出/出具 |
| `paused` | 加 `-pause-workers` | 任务只入队不执行：排队中的取消、按任务 ID 恢复、任务面板的状态刷新 |
| `quota` | 加 `-quota-jobs 1 -quota-results 2 -quota-admissions 3 -quota-queries 1` | 每身份限额的四种拒绝（进行中任务、保留结果、每小时提交、并发查询）与控制台的提示文字 |
| `nopdf` | 去掉 Typst 参数 | 能力里没有 pdf：导出 PDF 按钮不出现、PDF 预览/样例预览被明确拒绝、出具不可用 |
| `sweep` | 加 `-sweep-interval 1m` | 保留期清理（过期 24 小时后删除产物与快照；演示里的过期时间见 docs/OPERATIONS.md "Retention"） |

`-memory` 意味着重启即清空快照、任务与产物；模板、看板、布局在四个私有目录里，重启仍在（要全新环境就删掉 `idp-reporting-run/{templates,dashboards,layouts,backgrounds}` 下的文件后再起）。PostgreSQL 与对象存储模式需要数据库和 S3 兼容服务，CI 里跑，本机不做。

用户手册在演示地址上：`http://127.0.0.1:7811/console/manual/`（应用栏底部与登录卡上的"帮助"图标；本仓库 `docs/manual/index.html` 是同一份）。

## 2. 模拟器里有什么

一个身份：`platform_demo / user_a`（发行方 `urn:idp:contract-demo`），两个产品连接。没有第二个身份可登录，"另一个身份看不到我的东西"这类隔离只在 Go 测试里验证。

| 产品连接 | 数据集 | 列 | company_demo 可见的行 | 用来测什么 |
|---|---|---|---|---|
| `brant-contract-demo` | `receivables.aging@1.0.0`（时区 Asia/Shanghai，币种政策 ledger_base@1.0.0） | 客户 `customer.id`（文本）、账龄区间 `aging.bucket`（文本）、应收余额 `ar.open_balance`（decimal，2 位，CNY） | `customer_a / current / 100.25`、`customer_b / 1_30 / -0.24`、`customer_c / 31_60 / 9007199254740893.00`；服务端合计 `9007199254740993.01` | 精度（超过 2^53 的金额必须原样显示）、负数、合计与分页、分组出具（合同版本 2） |
| `shipment-contract-demo` | `shipments.daily@1.0.0`（无币种政策） | 目的国、服务、运单数 `shipment.count`（integer，单位 shipment） | `CN / express / 9007199254740993`、`DE / standard / 7` | 整数超大值、无币种的数据集、第二个产品连接的切换与目录刷新 |

两份数据各有一行 `secret`（`hidden / 999.99`、`US / hidden / 999`）**不在授权行里**，任何查询、快照、导出、出具都不应出现它；各有一行属于 `company_other`，输入 `company_other` 会被来源拒绝（控制台提示"当前身份无权访问"）。模拟器列出的公司名单（`GET /companies`，S19-B）只有 `company_demo`（名字"演示公司"），所以控制台的公司范围选择器（S09-D）只列它并已替人选好；`company_other` 只能在来源没有名单或名单不完整时的文本框里输入（DOM 测试拦截该路由做到这一点），多个公司以逗号分隔但只有 `company_demo` 会通过。数据时点可以任填，模拟器不按日期过滤。

两个数据集各自在目录里发布了可筛选与可排序的字段（ADR 0023，S20-A），控制台的查询面板按它们给出“筛选”与“排序”（S20-B）：

| 数据集 | 可筛选的字段：运算符 | 可排序的字段 |
|---|---|---|
| `receivables.aging` | 客户：等于、不等于、属于、开头为（文本，任填）；账龄区间：等于、属于（固定取值 `current`、`1_30`、`31_60`、`61_90`、`90+`，后两个没有行）；应收余额：小于、不大于、大于、不小于、介于（2 位小数，如 `100.25`） | 应收余额、客户（各自升序 / 降序） |
| `shipments.daily` | 目的国：等于、属于；服务：等于（只有这一个，面板只写这个词）；运单数：不小于、不大于（整数） | 运单数、目的国（各自升序 / 降序） |

没有日期或是/否类型的字段，也没有必填的筛选：那些控件由 DOM 测试拦截目录来走。筛选由模拟器在内存里应用，合计是筛选后的行的合计（如 账龄区间 属于 `1_30`、`31_60` → `customer_b`、`customer_c`，合计 `9007199254740892.76`）。

其他可用的"数据"：

- 样例包：37 个只读模板（`doctemplates/samples/`，四个业务域），每个自带样例行可预览；复制到我的模板要先有当前数据集（见第 4 节）。
- 每身份上限：模板 64、看板 16、布局 16、未过期结果 64、进行中任务 8、每小时提交 120、并发查询 4（默认值；`quota` 模式缩小）。
- 出具：模拟器声明合同版本 2（支持 2.0 分带模板按分组出具），编号前缀 `AR`（财务）/ `SH`（运单）；模板必须是**已发布版本**且画布无改动；出具失败路径（来源拒绝 `AUTH_SCOPE_DENIED`、未对账 `ISSUE_UNRECONCILED`、来源不可用）只能在 Go 测试里用 `SetUnavailable`/拒绝夹具触发，本机 UI 里触发不了。
- 作废（S24-A，ADR 0025）：两个模拟器都能应平台的请求作废一张已确认的单据——能出具的主体即可作废，编号不再使用，同一任务再次请求回答同一张回执；`GET /capabilities` 的 `issue_cancellation` 对两个模拟器的产品都是 `true`。控制台还没有入口（S24-C），目前只能经 API 触发：`POST /api/reporting/v1/issues/{id}/cancellation`，请求体 `{"reason": "…"}`；之后该文件的下载回 409 `ISSUE_CANCELLED`，出具记录带 `cancellation`。来源拒绝与不可用同样只能在 Go 测试里触发。

## 3. 一键造数据

```
node scripts/seed_demo_data.mjs --token-file ../idp-reporting-run/token --base http://127.0.0.1:7811 --out /tmp/seed.json
```

对正在跑的演示做：两个数据集各一次查询预览、一份冻结快照、一次 Excel 导出（有 Typst 时再加一次 PDF 导出）；8 个 1.x 模板（四个业务域、两个集合 `客户A`/`上海仓`、两个收藏、一个已归档、五个已发布、两个有第 2 版）；四个样例副本（对账单、波次拣货单、海运订舱、商业发票，按字段映射绑到应收余额数据集，对账单已发布）；两个看板（草稿、已发布三组件）；一个已发布的报表列布局（列序倒转）。脚本只走公开 API，可重复跑（每跑一次多一套，到上限会跳过并说明）；`--no-jobs` 跳过查询与任务，`--no-templates` 跳过 1.x 模板。

跑完登录控制台：模板中心有自己的模板与计数（收藏、归档、集合、业务域都有数）；看板工作室检查器“文件”页签的“高级 · 打开其他看板或指定版本 › 刷新我的看板”能列出两个看板；工作台的报表布局设计器的“历史”里标出已发布的版本（S09-F）。任务面板列出服务器上当前身份最近的 50 项任务（S07-C，`GET /jobs`），脚本建的快照与导出任务都在其中，最新在前；脚本仍把任务 ID 打印在结果表里（也写进 `--out` 指定的 JSON），粘进"恢复查看"就是"按 ID 恢复"场景的数据（列表之外、更早的任务只能这样打开）。数据芯片同样是"未选择数据"——会话数据不入库，先查一次或恢复一个快照任务后"查看结果"。

## 4. 场景矩阵

每行：场景 → 前置数据 → 怎么做 → 看什么。"自动化"一列说明已有哪种测试覆盖（DOM = `console/dom.test.mjs` 经真实 Go 服务；浏览器 = `scripts/browser_*_s0*.mjs`；基线 = `scripts/ux_baseline_s07.mjs`；Go = 服务端测试）。

### 4.1 登录与会话

| 场景 | 前置 | 做法 | 看什么 | 自动化 |
|---|---|---|---|---|
| 正确令牌 | `token` 文件 | 粘贴、连接 | 应用栏连接点变绿，页眉显示 `user_a`，落在报表工作台，空状态里是三步流程 | DOM、浏览器 |
| 错误令牌 | 任意字符串 | 连接 | 卡片内红字，令牌框清空，什么都不加载 | DOM |
| 退出 | 已登录且有查询结果、打开过抽屉 | 退出工作区 | 表格、任务、芯片、看板、模板中心全部清空；localStorage/sessionStorage 为空 | DOM |
| 401 中途失效 | 已登录 | 只能在 DOM 测试里拦截；本机可重启演示服务（`-memory` 下令牌不变，但会话资源丢失） | 页面清场回到登录卡，私有引用不残留 | DOM |

### 4.2 数据面板与工作台

| 场景 | 前置 | 做法 | 看什么 | 自动化 |
|---|---|---|---|---|
| 两个产品连接 | 无 | 数据面板（页眉芯片）里切换产品连接与数据集 | “数据集字段”的字段表（类型、币种/单位）随之变；切换后旧结果清空 | DOM、浏览器、基线 T7 |
| 旧地址 | 已登录 | 打开 `#overview`、`#catalog` | 都落在报表工作台；`#catalog` 同时拉开数据面板 | DOM |
| 预览 | `company_demo` | 查询预览 | 3 行；应收余额列右对齐，`9007199254740893.00` 一位不差；合计卡 `9007199254740993.01` | DOM、浏览器 |
| 越权公司 | `company_other` | 查询预览 | 提示无权访问，不显示任何行 | DOM |
| 隐藏行 | 任何查询 | 预览、快照、导出、出具 | 永远没有 `hidden` / 999.99 | Go、DOM |
| 快照与分页 | 预览后 | 创建快照；每页改为 2 行；下一页 | 徽标"冻结快照"，第 2 页同一内容，第一页/下一页可用 | DOM |
| 数据时点变化 | 有结果 | 改日期 | 结果立刻清空（旧结果不能冒充新查询） | DOM |
| 筛选与排序 | 应收余额数据集，`company_demo` | “添加筛选”点“账龄区间”→“属于”→ 勾 `1_30`、`31_60`；“添加排序”点“应收余额”→“降序”；查询预览；创建快照；导出 Excel | 还没填值时两个按钮不可用，旁边说明是哪一项筛选；2 行，`customer_c` 在前；合计卡“筛选后范围合计” `9007199254740892.76`；芯片以 `· 1 个筛选 · 按应收余额降序` 结尾；副标题与证据行写明范围；快照是同样的行与合计，工作簿 Metadata 末尾写出筛选与排序（S20-C） | DOM（S20-B）、浏览器、基线 T9；Go（S20-A、S20-C） |
| 筛选值的写法 | 同上 | 应收余额“不大于”填 `100`；“介于”填 `5.00` 至 `1.00` | 按钮不可用，说明“…的值须写成 2 位小数，例如 100.00。”、“…的起始值大于结束值：“介于”要求从小到大。”；改对后可查询；数字原样发给服务端（`9007199254740892.99` 与 `…893.00` 分得开） | DOM（S20-B）、浏览器 |
| 筛选随数据集 | 有筛选行 | 换数据集、换产品连接、刷新目录、退出 | 筛选与排序两块按新数据集的声明重来；结果清空；没有声明的数据集不显示这两块（DOM 测试拦截目录） | DOM（S20-B） |
| 服务端拒绝筛选 | 只能在 DOM 测试里拦截目录（页面上的声明比来源的多） | 查询预览、创建快照 | 提示“服务端不接受这组筛选或排序：…请核对筛选值，或刷新目录后重试。”，行留在面板上，没有结果也没有任务 | DOM（S20-B）、Go |
| Excel 导出 | 快照 | 导出 Excel | 下载 `report-<id>.xlsx`，提示"已通过摘要校验" | DOM、`scripts/verify_workbooks.py` |
| PDF 导出 | 快照 + `normal` 模式 | 导出 PDF | 下载 PDF；`nopdf` 模式下按钮不出现 | DOM（有 Typst 时） |
| 报表列布局 | 预览 | 展开"报表布局设计器"，改列序/对齐，按"发布" → "保存并发布"；"历史"里打开 v1、发布此版本（历史版本）、撤回发布 | 徽标 草稿 → 已发布 v1 → ·有未保存修改；屏幕表格按布局显示，Excel 仍导出完整列；两个身份互不可见只在 Go 里验 | DOM（S07-G）、浏览器、基线 T6 |
| 数据抽屉 | 任何页面 | 页眉芯片 / 看板起始卡 / 模板中心"选择数据…" | 查询面板搬进抽屉，结果到来抽屉自动关，芯片变为 `数据集 · 公司 · 时点 · 查询预览/冻结快照` | DOM（S07-A）、基线 |

### 4.3 看板工作室

| 场景 | 前置 | 做法 | 看什么 | 自动化 |
|---|---|---|---|---|
| 三种组件 | 预览或快照 | 添加指标卡、明细表、柱状图 | 指标卡是服务端合计；柱状图三行、零线居中、`-0.24` 向左、大数"小于绘图分辨率"标注 | DOM（S03-C4） |
| 运单数据集 | 切到 shipment 并预览 | 同上 | 整数 `9007199254740993` 原样；无币种时不显示币种 | 手工 |
| 结构面板 | ≥2 组件 | 上移/下移/移除 | 桌面顺序同步；首尾按钮禁用 | DOM（S06-C） |
| 保存/历史/发布 | 组件 | 保存 → 修改 → 发布 | 徽标 草稿 → 已保存 v1 → ·有未保存修改；"发布"给出"保存并发布"，确认后 已发布 v2；"历史"列出 v2 / v1（标出已发布与当前打开），可打开或发布此版本（回退） | DOM（S06-C、S07-B、S09-F）、浏览器 |
| 打开已发布的版本 | 已发布 | 历史 → 已发布的版本 → 打开 | 组件进入编辑器成为未保存的修改，数据来自当前授权查询，不是冻结的 | DOM |
| 配置文件 | 组件 | 文件页签 → 生成看板配置文件；改 JSON 粘回 → 打开 | 字段不在授权结果里、未知组件类型、超过 64 KiB、超过 12 个组件都被拒绝并说明 | DOM |
| 保存冲突 | 两个标签页打开同一看板 | 一边保存 v2，另一边再保存 | 冲突提示，要求刷新列表 | DOM |

### 4.4 模板中心与样例

| 场景 | 前置 | 做法 | 看什么 | 自动化 |
|---|---|---|---|---|
| 列表与筛选 | 造数据脚本 | 快速访问（全部/收藏/最近/归档）、业务域、集合、搜索、状态、排序、列表/卡片 | 计数与服务端一致；归档的不在"全部"里 | DOM（S06-B）、浏览器 |
| 收藏/分类/归档 | 自己的模板 | 星标；分类对话框加集合；归档；归档里恢复 | 写入带修订号；第二个标签页里同时改会得到 409 并刷新 | DOM |
| 样例预览 | 无需数据 | 任一示例 → 预览 → 生成 PDF 预览 | 用样例自带行出 PDF，带 PREVIEW 横幅；`nopdf` 模式下按钮禁用并说明 | DOM、浏览器 |
| 复制到我的模板 | 当前数据（预览即可） | 复制 → 映射对话框（每个槽位 → 字段或字面量）→ 复制并进入设计器 | 副本是 2.1 模板、版本 1，打开在工作室；没有数据时拒绝行提供"选择数据…" | DOM、基线 |
| 新建向导 | 当前数据 | 业务流程 → 版式（示例或空白 + 页面预设）→ 数据 → 名称 | 空白模板按预设（如 `label_100x100`）建，列取结果前几列 | DOM、浏览器 |
| 导入 JSON | 任一模板的导出 JSON | 导入模板 | 读入设计器为未保存修改，校验同"打开模板JSON" | DOM |

### 4.5 文档工作室

| 场景 | 前置 | 做法 | 看什么 | 自动化 |
|---|---|---|---|---|
| 1.x 单页模板 | 冻结快照 | 插入文本/绑定字段，拖动、吸附、对齐、撤销 | 安全区外、重叠、超过元素上限被设计器拒绝并在画布标出 | DOM（S03-I…L） |
| 2.0 分带模板 | 同上 | 重置为 2.0：页眉/报表头/明细/报表尾/页脚，添加明细表列 | 多页续页、承前过次、分组合计（分组字段 = 客户） | DOM（S03-L） |
| 2.1 条码/二维码/图片 | 同上 | 插入条形码（值 = 字段）、二维码、上传 PNG/JPEG | 模块宽度不足、图片超 512 KiB/2000px 被拒 | DOM（S03-M） |
| 页面预设与套印 | 2.x | 纸张与页边距看预设；套打：偏移、仅变量层、底稿 PNG | A4 之外的标签预设仍有印章条 | DOM（S06-B） |
| 边界样本检查 | 模板 | 检查与发布 → 边界样本 | 首行、末行、最长/最短值的行逐一校验，不渲染 PDF | DOM（S03-J） |
| PDF 预览 | `normal` | 预览与导出 | 按快照首行出 PREVIEW 标记的 PDF；页码器显示页数 | DOM |
| 历史/打开/撤回 | 保存两版 | “历史”：预览此版本、打开、发布此版本、撤回发布 | 打开 ≠ 发布；当前发布独立于保存 | DOM（S06-A、S09-F） |
| 保存并发布 | 有未保存修改 | 发布 | 对话框按钮"保存并发布"，脚注说明；确认后 已发布 vN | DOM（S07-B） |
| 正式出具（按行） | 已发布 1.x 模板、冻结快照 | 编辑器打开的是当前发布版本且不改动（控制台用“出具”页，S09-G）；出具面板选行号 | 任务先显示"编号待来源产品确认"，成功后 `No. AR-000001`，下载 `issued-AR-000001.pdf`；改过画布后出具被拒 | DOM（S03-G/H，有 Typst 时） |
| 正式出具（按分组） | 已发布 2.0 分组模板 | 出具面板选分组（如 customer_c） | 任务标题带分组键；运单数据集前缀 `SH` | DOM（S03-K） |
| 出具失败 | — | 本机 UI 无法触发（来源拒绝/不可用/未对账是 Go 夹具） | 见 `transport/httpapi` 与 `adapters/contractsim` 的测试 | Go |

### 4.6 任务面板

| 场景 | 前置 | 做法 | 看什么 | 自动化 |
|---|---|---|---|---|
| 面板在任何壳子上 | 有任务 | 在看板工作室/文档工作室里点应用栏"任务" | 列表与恢复行搬进面板，Esc 放回；"查看结果"落到工作台并关面板 | DOM（S07-B）、基线 |
| 筛选与加载更多 | 有不同类型、状态的任务（§3 造数据后再做一次出具或取消） | 面板里选类型、状态；任务超过 50 项时点“加载更多” | 只剩所选类型/状态的行，“N 项”随之变化而应用栏徽标不变；无匹配时显示“没有符合筛选的任务”；加载更多后更早的任务接在末尾，最后一页后按钮消失 | Go（`GET /jobs` 的 kind/state/before）、DOM（S07-E） |
| 列表来自服务器 | 造过数据（§3）或另一浏览器里建过任务 | 重新登录 → 应用栏"任务" | 面板直接列出当前身份最近的 50 项（最新在前），不必按 ID 恢复；计数卡与应用栏徽标同数；打开面板或"刷新状态"后别处新建的任务出现 | Go（`GET /jobs`）、DOM（S07-C） |
| 别人的任务不在列表里 | 两个身份的令牌（本机演示只有一个：看 Go 测试） | 换身份登录 | 列表只含该身份的任务；按 ID 恢复另一身份的任务得到"未找到" | Go（S07-C） |
| 排队中的任务 | `paused` 模式 | 创建快照 | 任务停在"排队中"，可取消；取消后状态"已取消"；恢复 UI 不会假装成功 | DOM（恢复夹具）、手工 |
| 按 ID 恢复 | 任一任务 ID（`-memory` 下重启前） | 刷新页面重新登录 → 面板 → 粘贴任务 ID → 打开任务 | 只能恢复当前身份的任务；伪造 ID 得到"未找到" | DOM |
| 过期清理 | `sweep` 模式 + 过期的结果 | 等清理（演示过期时间见 OPERATIONS） | 任务行显示"已过期并清除"，下载与查看结果消失 | Go（S04-B）、手工耗时 |

### 4.7 限额、并发与错误

| 场景 | 前置 | 做法 | 看什么 | 自动化 |
|---|---|---|---|---|
| 进行中任务上限 | `quota` 模式（1） | 连点两次创建快照 | 第二次被拒："已达到进行中任务上限 (1)"，页面不清空 | DOM（S04-D）、手工 |
| 保留结果上限 | `quota`（2） | 创建第三个快照/导出 | "已达到保留结果上限 (2)" | 同上 |
| 每小时提交上限 | `quota`（3） | 第四次提交 | "已达到每小时提交上限 (3)" | 同上 |
| 并发查询 | `quota`（1） | 两个标签页同时预览 | 其一"查询进行中过多" | Go、手工 |
| 服务过载 | `-max-in-flight 1` 起服务 | 并发请求 | 503 OVERLOADED，控制台"服务繁忙"，不清空结果 | Go、DOM |
| 未确认的提交 | 断网/关服务瞬间点创建快照 | 再点一次 | 同一待确认提交复用原 Idempotency-Key，不重复建任务 | DOM |
| 注入内容 | — | 只能在 DOM 测试里改响应 | 单元格、名称里的 `<img onerror>` 永远是文本 | DOM |
| CSP 与存储 | 任意 | 浏览器开发者工具 | 无内联脚本/样式；无 localStorage/sessionStorage/cookie；令牌不在 URL | DOM、Go（响应头） |
