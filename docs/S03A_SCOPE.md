## 当前完整切片

独立 Go 服务通过嵌入的 HTML/CSS/JavaScript 提供 /console/；界面与同源既有 API
连接。采用 Sites 本地开发/预览流程，不创建托管 Site、远程仓库或外部发布。

1. API 新增已认证 GET /api/reporting/v1/session，返回可信平台身份和明确产品连接
   ID；不返回 token、业务行、服务凭据或自动扩大授权。其余业务 API 语义不变。
2. 登录使用用户输入的现有 Bearer；仅存在内存，不进 URL、Storage、日志和错误体。
   不提供自动登录后门。退出/认证失效清除令牌、结果、任务引用并中止本会话请求。
3. 提供概览、数据目录、报表工作台、任务工作区及能力信息；以服务器返回值呈现，
   不伪造统计、任务或业务数据。明确显示当前合成数据/临时存储配置。
4. 目录选择采用已发布 dataset/metric/dimension/时区/币种组合。公司仅为待授权
   选择器；不支持的筛选、排序与公式不显示为可用。无任意 SQL。
5. 预览、异步快照、完成后冻结分页、导出任务与文件下载均调用真实既有 API。
   每个异步动作使用新幂等键；同动作重试保留 key。已提交任务不可因切换界面
   自动取消；取消是独立显式 API 动作。下载仍向服务器重查当前权限。
6. 所有金额/大整数以服务器字符串显示，不经 JavaScript Number。动态文本使用
   textContent，不能执行来自列名/单元格的 HTML 或公式。只在校验响应后渲染。
7. 本次会话的任务列表仅跟踪本会话已知任务；用户可用任务 ID 恢复服务器上的
   私有任务。未实现全量任务历史列表，不声称本地列表是数据库全部任务。
8. 401 清除会话；403/503/完整性或过期错误清除对应可见结果并明确原因。忽略
   退出、换产品或换查询前已开始但后来返回的陈旧请求。分页不混用快照/游标。
9. 静态资源白名单、严格 CSP/no-store/nosniff/frame-ancestors、键盘操作和响应式
   布局。所有 UI 权限由 API 校验，不依赖隐藏按钮。
