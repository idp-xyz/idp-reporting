# 文档工作室（S06-A）

2026-11-02。ADR 0008 决定控制台以用户的原型 `IDP_Reporting_Designer_UIUX_V3.0.html` 为界面规格；S06-A 把控制台的“文档模板设计器”页换成原型的全屏工作室。范围见 `docs/S06A_SCOPE.md`，差距清单见 `docs/UX_GAP.md`。本文件是工作室的地图（区域 → 函数）、偏离清单（每一处及其原因）、范围没有规定而我们做出的决定、与截图索引。

**保真规则（ADR 0008 §1）**：1440 px 下，工作室与原型在结构、标签、状态与间距上一致；每一处偏离都列在下面，原因是服务端规则、安全规则（CSP、无 `innerHTML`、令牌只在内存）或无障碍规则，不为口味偏离。“看起来是否一样”由人对截图判断（`evidence/s06a/`，脚本不会替人判断），本文件如实这样说。

## 范围文件没有规定、我们做出的决定

- “当前带”：所选元素所在的带；没有选择时用上一次插入的带，再没有则用“插入选项”里的所在带。
- 无名称的模板：已保存的显示“模板 <id 前八位>”，未保存的显示“未命名模板”；空名称不写入（删除 `name` 键）；JSON 里 `name: ""` 被控制台拒绝（服务端把空串当作“没有”，共享用例不含该例）。
- 已保存且有修改、从未发布：徽标写“已保存 v{n}·有未保存修改”（范围文件只列了四种）；已发布指针与已保存版本不同：写“已保存 v{n}”，指针在 tooltip 里。
- 运行版式检查：设计器自己的校验（设计器的配置恒合法，所以它的失败来自最近一次边界样本与最近一次预览拒绝的位置）；“版式检查未通过 · N 项”的 N 是这些问题的数量。不另调服务器。
- 粘贴：2.x 的线/矩形偏移 2 毫米，文本/条码/二维码/图片取最近的空位；1.x 取原位置上下最近的合法 y；2.x 与 1.x 之间不能互贴。剪切只在删除被接受时才删除（复制总是成功）。
- 格式刷：目标非文本时取消并说明；一次性；Esc 取消。2.x 复制字号/对齐/粗体/换行（换行只用于固定文字与字段文本），1.x 只有字号与对齐。
- 锁定只拦指针与键盘移动/调整大小（以及对齐、等距这两个会移动元素的操作）；属性输入里的数值仍可改（用户明确输入）；删除不受限。锁定与隐藏在换模板、登出时清空。
- 吸附关：拖动按 0.1 毫米落点，不吸附网格与其他元素的边。
- 恢复到编辑器：作为一步未保存修改载入（可撤销），`saved` 不变，所以随后保存产生新版本；发布指针不动。
- 发布某个非当前打开的保存版本：不要求编辑器内容与已保存一致（发布的是服务端那个不可变版本）；发布当前版本仍要求无未保存修改。
- 模板选择只让打开“绑定的数据集与当前冻结快照相同”的模板（其他的显示原因）。列表的名称/数据集/已发布版本要逐个读（每个模板两次请求），所以打开对话框时才读。
- 抽屉：查询表单与行表格是控制台的既有元素，抽屉打开时被搬进去，关闭时放回原位（嵌入页里它原本在起始卡片里）。
- 控制台 `notice` 在工作室打开时浮在底部（否则被全屏工作室遮住）。
- 页数：从 PDF 的页树读（`/Type /Page` 叶子数与 `/Count` 取较大值）；读不出则 1。

## 键盘与无障碍

功能区、竖向工具栏与检查器各是 `role="tablist"`（箭头、Home、End，roving tabindex）；所有对话框与抽屉 `role="dialog"` `aria-modal="true"` `aria-labelledby`，焦点进入、Tab 在其中循环、Esc 与点击遮罩关闭、焦点回到打开它的控件、背后的工作室 `inert`；每个控件有名称；状态栏选中文本是礼貌的 live 区；窄屏侧栏与检查器抽屉按 Esc 关闭。画布的快捷键不变（方向键微调、Delete、Ctrl/⌘ D、A、Z、Y、K），新增 Ctrl/⌘ C、X、V、S 与按住 Space 拖动平移。

## 范围文件没有规定、我们做出的决定

- 列表路由新增四个键：`name`（最新版本的名称，没有则空）、`schema_version`、`preset`、`published_version`，都是附加键。原因：卡片要名称、预设与发布状态，而读一个版本会记下“最近打开”（`last_opened`），逐个读会让每个模板都成为“最近使用”；服务端一次给出（Go：`transport/httpapi/private_documents.go` 的 `summary` 参数，仅文档模板传入；`TestListingCarriesWhatACardShowsAndOpensNothing` 断言列表不改变 `last_opened`）。
- 业务域与流程在目录里存样例包自己的中文标签（“仓储 WMS”“入库”……），不是代号；四个业务域与各自流程是固定表（`DOMAINS`），与原型一致。
- 工作室的 A6 模板选择对话框保留，只在没有模板中心的页面（嵌入页）里由面包屑打开；控制台里面包屑、字标、左侧栏“模板”按钮都去模板中心。
- 模板中心每次显示都重读本身份的模板列表（最近打开与修订会变），样例包只读一次。
- 空白模板：2.0，只有明细带，明细表宽为预设的版心宽，列取结果的前 6/4/2 个字段（版心 ≥ 150 / ≥ 100 / 更窄毫米）；A4 不写 `page`。
- 向导里选了流程的空白模板，保存后写目录元数据（域、流程）；选“空白模板”（不属于任何流程）则不写。
- 映射表里字面文字的默认值是 `[标签]`（与服务端对未映射槽位的默认一致）；类型相容：文字槽可映射任何字段，整数槽只映射整数，小数槽映射小数或整数，日期槽映射日期/时间类型；数据集字段类型 `string` 视同文字。
- 目录写入同一模板排队串行；收到 409（修订过期）就刷新列表并提示，不自动重试（用户的意图可能已过时）。
- 没有服务端 PDF 渲染时，预览对话框仍显示字段表，“生成 PDF 预览”为 `aria-disabled` 并说明。
- `documents.openServer(id, version, then)` 新增第三个参数（打开成功后调用），`documents.bridge` 新增（`ready`、`binding`、`columns`、`nameOk`、`blank`、`importJSON`、`openServer`）；工作室本身的行为不变。

# 看板工作室（S06-C C6）

看板设计器成为自己的一种工作室：文档工作室的区域（顶栏、工具栏、侧栏、工作区、检查器、状态栏、对话框）围着看板既有的控件；`dashboard.js` 的每个函数与每个 id 都在（DOM 测试按 id 驱动看板），只新增一个状态读取（`state()`）、一个变化通知（`ports.changed`）和返回 Promise 的动作；`board.js` 是外壳层，只切面板与页签、从看板自己的状态推导徽标、把它的文字镜像到各区域、在结构面板里代理卡片的按钮、跑发布确认与帮助对话框、在窄屏开抽屉。它不写标记、不写样式属性、不加载、不存储。

## 偏离与决定

| # | 之前 | 现在 | 原因 |
|---|---|---|---|
| 1 | 控制台页面有 222 px 导航列；工作室与中心隐藏它，各自提供出口 | 56 px 应用栏在所有壳子上；三个全屏盒子从它右侧开始（`--app-rail`）；原型里的字标、面包屑、返回设计器都保留 | ADR 0009 §2；原型没有规定屏幕之间的通道 |
| 2 | 看板起始卡与数据面板“回工作台查询”；模板中心说“先在报表工作台查询” | 都变成“选择数据…”打开抽屉 | ADR 0009 §4 |
| 3 | 应用栏标签 | 可见的是两字短标签（报表、看板…），`aria-label` 是全名 | 56 px 放不下全名；屏幕阅读器读全名 |
| 4 | — | ≤ 700 px 应用栏变成顶部 48 px 横条，壳子从它下方开始 | 手机宽度没有竖栏的位置 |
| 5 | 嵌入页 | 没有应用栏、芯片与抽屉；看板区段里的三个“选择数据…”按钮由页面规则隐藏（查询面板本就在视图里） | ADR 0006：嵌入页没有导航 |
| 6 | 文档工作室的“参数与筛选”抽屉 | 保留，不变；它搬的是同一个查询面板 | 原型的屏幕内部，不动 |

# 任务面板与保存并发布（S07-B）

> S07-C：面板的列表是服务器的 `GET /jobs?limit=50`（`app.js` `loadJobs`）：登录后、面板打开时（后台静默读取，不占用页面）与“刷新状态”（先读列表，再逐项轮询）；本会话恢复的、列表之外的任务保留在列表末尾。页面文案：“我的任务”“服务器上当前身份最近的 50 项任务”。

2026-11-04。`docs/S07B_SCOPE.md`。

| 区域 | 控件 | 函数 |
|---|---|---|
| 应用栏“任务”（`data-panel="tasks"`） | 打开/关闭任务面板；`aria-expanded` 跟随 | `app.js` `tasksPanel`（与数据抽屉同一个 `makeDrawer`）：把任务页的恢复行、列表卡与“刷新状态”搬进 `#sh-tasks-slot` / `#sh-tasks-foot`，关闭时放回；两个抽屉互斥；`openPage` 关闭所有抽屉（“查看结果”因此落到工作台） |
